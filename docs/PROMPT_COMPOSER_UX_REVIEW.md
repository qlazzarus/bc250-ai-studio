# P6-UX-R2 — 사전 구성 사용성 재검토

작성일: 2026-11-16 · 기준 소스 `730e077` · 우선순위: **남은 개선 작업 중 최우선**.
상태: 소스·화면 구조 검토 완료, 재설계/구현/실제 화면 검증 대기. 이번 브라우저 inventory는 `The browser access host is unavailable`을 반환했다. 아래는 실제 화면의 새 관찰이나 사용성 측정 결과가 아닌 JSX·CSS·상태 흐름 분석이다.

기존 P6-UX의 카테고리·그룹·자동 미리보기 구현과 2026-11-15 기능 검증은 [archive](archive/prompt-composer/2026-11-16/README.md)에 보존한다. 기능이 동작하고 가로 넘침이 없었다는 결과를 장면 구성 도구의 사용성이 충분하다는 판단으로 확대하지 않는다. P5-C03 접근성 검증과도 별도 항목이다.

## 목표 화면 흐름

모델 선택 → 카테고리/검색으로 탐색 → 선택한 장면 요약 → 필요할 때 추가 설명/후보 제안 → 최신 미리보기 확인 → 명시적 적용 → 최종 입력 수정·생성.

데스크톱에서는 충분한 작업 폭 안에서 탐색과 장면 요약/미리보기를 나란히 보여 주는 안을 우선 검토한다. 현재 좁은 컬럼을 그대로 두고 내부만 다시 분할하지 않는다. 모바일에서는 탐색을 기본으로 두고 선택 개수·미리보기 진입과 적용 상태를 쉽게 찾도록 한다. 고정/하단 적용 영역은 360/390px 및 소프트 키보드에서 콘텐츠를 가리지 않는지 검증한 뒤 도입한다. 새 모달·라이브러리·App 전면 재작성은 기본안에 포함하지 않는다.

구체적인 수정 파일·선행 조건·검증·인계는 [U01–U12 실행 태스크](PROMPT_COMPOSER_EXECUTION_TASKS.md)에 분리했다.

## 실행 순서와 완료 조건

1. **구조 확정:** 빈 상태, 6개 분류에 8개 선택, 원문 포함/별도 보관, 최종 직접 수정, 과거 복원 상태의 데스크톱·360/390px 화면안을 만든다. App 변경은 작업 폭과 배치에 필요한 최소 범위를 먼저 제시한다.
2. **UI 구현:** PromptBuilder의 영역·문구·탐색 복구·적용 동작을 정리하고 CSS를 조정한다. 선택 순서/ID/Scene v1, compiler output, 서버 계약, 직접 생성, applied 기록, 덮어쓰기 확인과 retry를 보존한다.
3. **검증:** 같은 장면을 기존/개선 화면에서 구성하며 스크롤 왕복·탐색 클릭·적용 위치 찾기·포함 여부 혼동을 비교 기록한다. 이번 검토에서는 수치를 측정하지 않았다. 키보드 순서/포커스·작은 제거 버튼·360/390px·실제 확대도 확인한다.
4. **완료 판정:** 핵심 시나리오를 실제 브라우저로 통과하고, 사용자에게 최종 화면을 보여 장면 구성 흐름의 개선 여부를 확인한 뒤 닫는다. 단위 테스트 통과만으로 사용성 완료 처리하지 않는다.

필수 시나리오: 검색+필터와 전체 검색 복귀, 필터 밖 선택 유지, 개별/전체 해제와 취소, 원문 중복 없이 반영, 자동 미리보기와 마지막 applied 분리, 덮어쓰기 취소, 같은/다른 계열, capability fallback, 복원 시 과거 사실 보존, validation 오류, 직접 생성·retry.

## 우선순위 결정

P6-UX-R2를 운영 릴리스 준비, Actions 속도 최적화, renderer/LLM/Scene v2 기능 확장보다 먼저 수행한다. 기존 P5 데이터 정합성 회귀 검증과 접근성 잔여 항목은 유지한다. 현재 사용성 개선 없이 기능만 추가해 화면을 더 길게 만드는 작업은 뒤로 둔다.
