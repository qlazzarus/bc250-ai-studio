## 문서 관리 기준

현재 구성 문서에는 구현된 동작과 제약만 둔다. 예정 기능과 검증 대기는 TODO에 두고, 상세 실행 명세가 필요한 작업만 별도 계획서를 연결한다. 완료한 작업은 현재 구성에 반영하고 TODO에서 제거한다. 날짜별 진행률·완료 원장·실행자 인계 로그를 누적하지 않는다. API 필드와 모델 기본값은 코드·설정이 기준이며 같은 표를 여러 문서에 복제하지 않는다.

`docs/evidence/`는 기존 검증 산출물이며 현재 통과 상태를 대신하지 않는다. 문서 정리 과정에서 테스트·스크립트·이미지 산출물은 삭제하지 않는다.
