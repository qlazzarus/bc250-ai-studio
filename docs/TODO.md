## LLM Client 연동과 후보 코드

모델 전환 제품 구현은 외부 Client 프로젝트 소유다. 다음은 이 저장소 후보를 실제로 채택할 때 남은 통합 조건이며 일반 Studio 릴리스의 선행 조건이 아니다.

- [ ] Studio owned protocol 3과 후보 gate protocol 2의 계약 불일치 해결 또는 검증된 외부 gate 사용.
- [ ] 공통 GPU 잠금 inode·소유권·부팅 생성, 서비스 계정·root worker·Unix 소켓·polkit·SELinux와 역할별 키 경계 검증.
- [ ] 직접 llama 호출자, 신규 이미지 요청, DB 쓰기의 지속 차단과 실제 GPU 유휴 검사. 순간 slots/프로세스 조회만으로 지속 차단을 대체하지 않기.
- [ ] journal·hold 소유권/세대 보존, 응답 유실·프로세스 종료·재부팅·수동 Client 재시작 후 재진입과 실패 복구. 락은 프로세스 종료 후 유지되지 않음을 반영.
- [ ] 후보를 설치한다면 인증된 release 전달부터 백업·설치·health·부분 실패 롤백까지 실제 어댑터로 연결. 코드·DB/WAL·환경·gate 상태를 호환 단위로 복원.
- [ ] 후보 코드와 활성 Studio 경로의 중복 정리는 외부 소유 프로젝트의 채택 범위를 확인한 뒤 수행.
